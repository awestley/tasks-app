# Project instructions

Tasks is a personal task tool, not a product marketing site. Keep interfaces focused on tasks, navigation, settings, and useful status. Do not add promotional landing pages, slogans, motivational messages, decorative overview cards, upsells, or sample tasks by default. Use short, factual interface copy. Keep the web, macOS, and iOS interfaces consistent with this preference.

Deployment and Apple Developer credentials will be provided later. Continue local implementation and verification without requesting those details again unless work requires them.

Never use an em dash in responses to the user.

Do not show a product name in the interface. Keep the existing blue checkmark icon; use generic labels such as Tasks only where a browser tab or installed app requires a name.
